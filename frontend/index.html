Your code is correct, but note that Path(pa) does not check whether the folder exists. It only creates a Path object representing that path.

Python 
from pathlib import Path

pa = "data/pdf/frist_sem"
file = Path(pa)

print(file)
Output
data/pdf/frist_sem

If you want to check whether the folder exists, use:

Python 
from pathlib import Path

pa = "data/pdf/frist_sem"
file = Path(pa)

print(file)
print(file.exists())
